## Hardware Requirements
* 65C02 CPU
* 65C22 VIA
* 6551 ACIA
* AT28C256 ROM
* 62256 RAM
* 74HC00 NAND Gate
* NE555 Timer (Optional)
* LM386 Op-amp
* CIG25-1605N VFD
